# 04. Backend и QA REF-01

## Реализовано

- Core хранит профиль, переходы, атрибуцию и первую оплаченную покупку.
- Card service создаёт карту и проводит 2 000/500 только через ledger.
- Уникальные ключи платежа и транзакций обеспечивают идемпотентность.
- Auth валидирует код и устройство до создания аккаунта, затем фиксирует атрибуцию.
- Billing выдаёт награду только после подтверждённого `paid`.
- Удаление аккаунта очищает реферальные персональные связи.
- Gateway маршрутизирует публичный visit и закрытый кабинет.

Миграции: core-service `0017_referrals.sql`, card-service `0010_referrals.sql`.

## Проверено

- production-сборка auth, card, core и gateway;
- чистое применение миграций;
- TypeScript-проверка card/core/gateway;
- полный smoke: **281 успешно, 0 провалено**;
- одноразовые 2 000 и 500, self-referral `409`, повторный callback без дубля;
- связь карты с аккаунтом и исключение карты реферера из freeze/burn.
