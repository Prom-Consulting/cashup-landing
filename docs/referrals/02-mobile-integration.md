# 02. Интеграция REF-01 на mobile

1. Кнопка «Стать реферером» вызывает `POST /v1/me/referrals/enroll`.
2. Экран реферера читает `GET /v1/me/referrals` и показывает ссылку, статистику и список.
3. Для ссылки доступны действия «Скопировать» и системное «Поделиться».
4. Начисления из `GET /v1/me/history` отображаются с `kind: "referral"`.
5. Регистрация после web-перехода передаёт `referralCode` и постоянный `deviceId`.

## Приёмочный сценарий

1. Дважды подключить реферера — стартовый баланс остаётся 2 000.
2. Зарегистрировать приглашённого с другим постоянным `deviceId`.
3. Регистрация с устройства реферера получает `409` и не создаёт аккаунт.
4. После первой успешной оплаты баланс реферера становится 2 500.
5. Повторная доставка оплаты не меняет баланс и статистику.

Полные тела запросов и ответов: [`../../API.md`](../../API.md), раздел `REF-01`.
