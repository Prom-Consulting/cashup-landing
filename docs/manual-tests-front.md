# Ручная проверка фронта: заявки, удаление, восстановление, OctōPAY

Те же сценарии, что в `docs/manual-tests.md` (бэкенд), но руками через интерфейс. Номер пункта
совпадает с разделом там. Где кнопки нет — сказано, как проверить через API.

Нужно: суперадмин в admin.loal.kg, 3–4 тестовых номера с WhatsApp, один тестовый аккаунт OctōPAY.
После каждого шага обновляйте страницу (Cmd+Shift+R), если открыт старый экран.

## Где что лежит

| Что | Где |
|---|---|
| Статусы, фильтры, заявки без заведения | admin → «Заведения»: фильтры «Ждут проверки», «Заявки без заведения», «Работают», «Приостановлены», «Архив»; галочка «Показать удалённые» |
| Подтвердить / отклонить | admin → карточка заведения «ждёт проверки» → «Подтвердить заведение» / «Отклонить» |
| Отклонить заявку без заведения | admin → «Заведения» → «Заявки без заведения» → «Отклонить» на карточке |
| Удаление с выбором OctōPAY | admin → карточка → «Удалить заведение» (выбор «Только из Loal» / «Из Loal и из OctōPAY», если есть OctōPAY) |
| Вернуть из архива | admin → «Показать удалённые» → карточка удалённого → «Вернуть заведение…» |
| Смена номера сотрудника | admin → карточка → «Команда» → «Сменить номер» у человека |
| Перенос OctōPAY | admin → карточка → «Аккаунт OctōPAY» → выбрать заведение → «Перенести сюда» |
| Выход из программы | partner → «Настройки» → «Выход из программы Loal» (у OctōPAY — выбор «Только из Loal» / «Из Loal и из OctōPAY») → admin → «Выход партнёров» |
| Google | partner/cashier → «Настройки» → «Вход через Google»; экран входа → «Войти через Google» |
| Заявка с сайта | loal.kg/become-partner |
| Код в Telegram | любой вход по коду → «Куда прислать код» → Telegram (видно, только если на сервере задан ключ) |
| Пароли партнёров | admin → «Пароли партнёров»; partner → вход по номеру и паролю, «Нет пароля или забыли? Войти по коду» |
| Поддержка | partner → «Поддержка»; admin → «Поддержка» |

## 1. Заявка с лендинга
- [ ] loal.kg/become-partner, «Только лояльность» → в конце «Заведение ожидает проверки». В admin: фильтр «Ждут проверки», у карточки «Заявка с сайта · Только Loal».
- [ ] Отправить ту же форму ещё раз → тот же экран статуса, без ошибки.
- [ ] Поменять название и отправить с того же номера → «По этому номеру уже обрабатывается заявка с другими данными…».
- [ ] Номер кассира или владельца живого заведения → «Этот номер уже работает в заведении Loal…».
- [ ] «OctōPAY + лояльность» до одобрения → на экране статуса нет ссылки на OctōPAY и не просят пароль.
- [ ] Одобрить её в admin («Подтвердить заведение») → через несколько секунд на лендинге (обновить статус) появилась ссылка на OctōPAY. В карточке admin «аккаунт OctōPAY готов».
- [ ] Номер, у которого аккаунт OctōPAY связан с другим заведением → после одобрения в карточке «OctōPAY не открыт» и подсказка «…связан с другим заведением — перенесите его сюда». На лендинге пароль не просят.
- [ ] Номер, чей аккаунт OctōPAY удалён меньше 30 дней назад → «…удалён меньше 30 дней назад…».

## 2. Отклонение
- [ ] Карточка «ждёт проверки» → «Отклонить» без причины → ошибка у поля «Напишите причину».
- [ ] С причиной → «Отклонено. Владелец получил причину в WhatsApp» (или «не дошло»). Карточка переходит в «Заведение отклонено», причина видна, в списке — фильтр «Архив», бейдж «Отклонён».
- [ ] В отклонённой карточке «Отправить причину снова» → без ошибки, причина прежняя.
- [ ] Одобренное заведение: кнопки «Отклонить» нет (только у «ждёт проверки»).
- [ ] После отказа: на лендинге войти тем же номером (новый код) → снова пустая форма, новая заявка принимается.
- [ ] «Заявки без заведения» → «Отклонить» с причиной → карточка остаётся в фильтре с бейджем «Отклонён» и причиной.

## 3. Экран «Заведения»
- [ ] Бейджи: «Ждёт проверки», «Работает», «Приостановлен», «Отклонён», «Удалён» (строка «можно вернуть до …»), «Данные стёрты».
- [ ] Числа на фильтрах сходятся с карточками. Поиск по названию и телефону работает и в заявках.
- [ ] Старое: создание заведения, «Показать удалённые», переход в карточку.

## 4. Один номер — одно заведение
- [ ] admin → «Новое заведение» на номер владельца другого живого заведения → ошибка у поля телефона «…уже работает в другом заведении…».
- [ ] Карточка → «Команда» → добавить человека, который уже работает в другом заведении → ошибка у телефона.
- [ ] Удалить заведение → его номер сразу можно указать владельцем нового заведения.

## 5. Смена номера сотрудника
- [ ] «Сменить номер» → номер, работающий в другом заведении → «…уже работает в другом заведении — код не отправлен».
- [ ] Свободный номер → «Отправить код» → в WhatsApp пришло «для смены номера в Loal».
- [ ] «Отправить код снова» раньше минуты — кнопка заблокирована с отсчётом.
- [ ] Неверный код → «Неверный код. Номер не изменился», в «Команде» прежний номер.
- [ ] Верный код (отправляется сам после 6-й цифры) → «Номер сменён на …», в «Команде» новый номер с той же ролью и филиалами.
- [ ] Старым номером войти в partner → заведения нет. Новым → входит с той же ролью.
- [ ] Номер владельца = контактный → в «Реквизитах» телефон тоже новый.
- [ ] В partner у владельца и кассира кнопки смены номера нет.
- [ ] Заведение с OctōPAY, меняем контактный номер → в OctōPAY вход по новому номеру; номер, занятый в OctōPAY, → «…занят в OctōPAY другим аккаунтом — в Loal ничего не изменилось».

## 6. Выход из программы
- [ ] partner (владелец, тариф OctōPAY + Loal) → «Настройки» → «Подать заявку на выход» → выбор «Только из Loal» → отправить. В admin «Выход партнёров» видно «Уходит только из Loal — аккаунт OctōPAY останется» → «Подтвердить выход» → заведение удалено, вход в partner закрыт, в OctōPAY аккаунт работает.
- [ ] То же с «Из Loal и из OctōPAY» → в admin жирным «аккаунт OctōPAY тоже закроется», после подтверждения OctōPAY закрыт.
- [ ] Магазин без OctōPAY → выбора нет, только «Только из Loal».
- [ ] Владельцу пришёл WhatsApp о решении.

## 7. Удаление суперадмином
- [ ] Заведение с OctōPAY → «Удалить заведение» → в окне выбор, по умолчанию «Только из Loal» → удалить → OctōPAY жив.
- [ ] «Из Loal и из OctōPAY» → кнопка «Удалить с OctōPAY» → аккаунт OctōPAY закрыт.
- [ ] Без OctōPAY → выбора нет, обычное «Удалить».
- [ ] Удалённое заведение открывается только на чтение (история списаний и счетов), правок нет.

## 8. Восстановление
- [ ] «Показать удалённые» → удалённое → «Вернуть заведение…» → список людей: «вернётся» / «номер работает в другом заведении…», строка про OctōPAY, «Можно вернуть до …».
- [ ] Все свободны → «Вернуть заведение» → карточка снова рабочая, сверху «Заведение возвращено из архива» с итогом. Люди входят и видят заведение.
- [ ] Google, привязанный у владельца до удаления, снова пускает.
- [ ] Номер владельца занят → кнопка «Вернуть» неактивна, пока не подтвердить новый номер (номер → код → «вернётся с номером …»). После возврата владелец с новым номером, контактный номер обновлён.
- [ ] Занятый кассир помечен «не вернётся», в итоге «не вернулись: 1».
- [ ] Аккаунта прежнего владельца нет → блок «Новый владелец: прежнего аккаунта больше нет» (номер + код).
- [ ] Отклонённое → «Вернуть» → снова «Ждёт проверки», отметки отказа нет, заявка снова видна на лендинге.
- [ ] После возврата прежняя одобренная заявка на выход в partner не показывается, можно подать новую.
- [ ] Удалено «из Loal и OctōPAY» → вернуть → в итоге «Аккаунт OctōPAY вернулся». Удалено «только из Loal» → «…владелец заново привяжет аккаунт кодом из OctōPAY» (partner → «Обзор» → привязать код).
- [ ] Удалить → вернуть → удалить → вернуть: всё отрабатывает.
- [ ] Прошло 30 дней → вместо возврата «Данные стёрты», кнопки нет.

## 9. Google
- [ ] partner → «Настройки» → привязать Google → «Привязан …». Выйти → «Войти через Google» → пускает.
- [ ] Сменили номер владельца (п. 5) → новый человек привязывает тот же Google → получилось; старый номер через этот Google не входит.
- [ ] Google, который открывает другое живое заведение → «Этот Google привязан к другому активному заведению — отвяжите его там» (чужое не названо).
- [ ] Уже привязан свой → другой не привязать («…сначала отвяжите его»), «Отвязать Google» → можно.

## 10. Перенос аккаунта OctōPAY
- [ ] Карточка B → «Аккаунт OctōPAY» → выбрать A → «Перенести сюда» → «Аккаунт OctōPAY теперь у этого заведения». У B тариф «OctōPAY + Loal», у A — «Только Loal». Если у B было «OctōPAY не открыт» — теперь «готов».
- [ ] У B уже свой аккаунт → «У этого заведения уже свой аккаунт OctōPAY».
- [ ] Повторно с A → «У выбранного заведения нет связи с OctōPAY…».

## 11a. Код в Telegram
- [ ] На сервере задан `TELEGRAM_OTP_API_KEY` → на входе (client, cashier, partner «Войти по коду») есть выбор WhatsApp / Telegram.
- [ ] Telegram → пришло «Verification code» от Telegram → код подходит. Выбор запомнился после перезагрузки.
- [ ] Номер без Telegram → «Не удалось отправить код в Telegram…», переключиться на WhatsApp — код приходит.
- [ ] Повтор раньше минуты — кнопка с отсчётом; неверный код — «Неверный код».
- [ ] Ключ убран → выбора нет, только WhatsApp.

## 11b. Пароль для бизнеса
- [ ] admin → «Пароли партнёров»: владельцы и администраторы филиалов работающих заведений, кассиров нет. Счётчики сходятся.
- [ ] «Отправить» у одного → в WhatsApp пришли сайт, логин и временный пароль; статус «Временный отправлен».
- [ ] partner → вход этим паролем → экран «Придумайте свой пароль», дальше кабинета не пускает → задать → кабинет. В admin «Свой пароль».
- [ ] Вход старым временным — «Неверный номер или пароль». 10 неверных подряд — «Слишком много попыток…».
- [ ] Уже вошедший по коду владелец (сессия до перехода) → при открытии кабинета экран «Теперь вход — по паролю».
- [ ] «Нет пароля или забыли? Войти по коду» → код → новый пароль → сразу в кабинете. Номер кассира → вход, кабинет отправляет в cashier.
- [ ] «Настройки» → смена пароля: неверный текущий — ошибка у поля, из кабинета не выкидывает.
- [ ] «Отправить всем без пароля» → прогресс, «Остановить» работает, недоставленные перечислены.
- [ ] «Сбросить» у человека со своим паролем → подтверждение → новый временный, свой перестал работать.

## 11c. Поддержка
- [ ] partner (владелец) → «Поддержка» → «Задать вопрос» → тема и вопрос → ветка «Ждёт ответа».
- [ ] admin → «Поддержка»: число у пункта меню, вопрос в «Ждут ответа» с названием заведения → ответить → «продублировали в WhatsApp», в WhatsApp владельцу пришёл ответ со ссылкой.
- [ ] partner: у «Поддержки» число непрочитанных, у вопроса «Есть ответ» → открыть → число пропало.
- [ ] «Вопрос решён» → «Закрыт»; новое сообщение снова открывает вопрос, в admin он опять в «Ждут ответа».
- [ ] Администратор филиала видит только свои вопросы; кассир раздела не видит (на сервере 403).
- [ ] Телефон: список, по нажатию переписка и «Все вопросы» назад.

## 11. Регресс
- [ ] Вход по номеру и коду (клиент, кассир, владелец), вход через Google.
- [ ] Касса: списание бонусов, «Счёт клиенту».
- [ ] Каталог loal.kg/partners: подтверждённое заведение появилось, удалённое пропало (до минуты).
- [ ] Оплата через OctōPAY со списанием бонусов.
- [ ] Добавление и удаление сотрудников, филиалы.
- [ ] Витрина: загрузка логотипа и фото в WebP, HEIC, AVIF.
