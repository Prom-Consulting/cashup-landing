# Ссылки на промокоды и редактирование

В админке в разделе «Промокоды» у клиентского кода есть «Скопировать ссылку»:
`https://client.loal.kg/register?promo=LOAL-7KX2QM`.
Адрес берётся из `CLIENT_APP_URL`, код нормализуется и проверяется.

Кабинет клиента сохраняет код на время регистрации (в пределах вкладки, до 30 дней).
После входа по WhatsApp он автоматически вызывает `POST /v1/me/promo-code` с токеном
вошедшего пользователя. Карта создаётся существующим процессом регистрации.
Ссылка работает и для уже зарегистрированного клиента; у уже вошедшего пользователя
промокод применяется сразу. Ограничения кода проверяет сервер. Повторное применение
`PROMO_ALREADY_USED` не выдаёт месяцы повторно и показывается как уже применённое.
Ошибка кода не отменяет регистрацию; при временном сбое есть кнопка повтора.

«Изменить» открывает действующую настройку: активность, лимит, дату окончания и заметку.
Сохраняется `PATCH /admin/v1/promo-codes/{id}`. Пустые лимит/дата/заметка — `null`.
Если дату не меняли, её поле в PATCH не отправляется — точное время остаётся прежним.
Код, аудитория и месяцы по текущему API неизменяемы: для них создают другой промокод.
История и уже выданные месяцы сохраняются.

Изменение не требует миграции или выкладки бэкенда. Нужно собрать и выложить
`apps/admin` и `apps/client`.
